- **(보안 관점)** 오늘 보안 반에서 나온 얘기: "보안을 생각하면 결국 자체 AI를 만들어야 한다." 외부 AI에 데이터를 넘기는 순간, **AI가 그 데이터를 판별·처리하는 그 지점이 곧 보안 노출 지점**이 된다. ML을 처음 배우면서 "좋은 데이터가 중요하다"는 말을 들었는데, 보안 반에서는 한 겹 더 들어가서 "그 좋은 데이터를 어디서 누가 보느냐"가 문제가 된다. 데이터 품질과 데이터 보안은 같이 가는 얘기라는 게 오늘 가장 크게 남았다.
- 과대적합 = 훈련 데이터를 "외워버린" 상태, 일반화 = 안 본 데이터에서도 맞히는 상태. 결국 **ML의 목표는 외우게 하는 게 아니라 일반화시키는 것**이라는 게 한 문장으로 와닿았다.
- 회귀와 분류의 갈림길은 결국 **정답(y)이 연속값이냐 이산값이냐** 하나로 정리된다. 부동산 가격(연속) = 회귀, 붓꽃 품종(이산) = 분류.

## 1. AI / 머신러닝 / 딥러닝의 관계

### 핵심 개념
- **인공지능(AI)**: 환경을 지각하고, 경험을 학습하여, 결과를 추론하는 지적 능력을 가진 시스템.
- **머신러닝(ML)**: AI의 한 분야. 주로 Excel/CSV/DB 같은 **정형 데이터**를 다룬다.
- **딥러닝(DL)**: ML의 한 분야. 주로 이미지/비디오/음성 같은 **비정형 데이터**를 다룬다.

### 상세 내용
- 포함 관계: `AI ⊃ ML ⊃ DL`.
- AI 종류: 약인공지능(ANI, 특정 분야 특화 — 알파고/스팸필터), 강인공지능(AGI, 인간 수준 범용), 초인공지능(ASI, 인간을 넘어선 수준).
- 머신러닝 정의 (톰 미첼): 과제 **T**, 성능 **P**, 경험 **E**. E(데이터)가 쌓일수록 P(성능)가 올라가면 학습했다고 본다.
  - 개/고양이 분류 예: T = 분류, P = 구분 능력(확률), E = 분류해 본 경험(데이터).

## 2. 머신러닝 절차

### 핵심 개념
- `데이터 수집 → (EDA / 데이터 분석) → 전처리 → 훈련(모델 생성) → 평가 → 배포(추론)`

### 상세 내용
- **EDA(탐색적 데이터 분석)**: 요약 통계·그래프로 데이터 구조/형태/노이즈를 먼저 파악.
- **전처리**: 결측값·이상값·과제와 무관한 데이터를 제거해 모델에 적합하게 정제. 강의에서 "데이터 선별이 제일 중요"라고 반복 강조했다.
- **훈련**: 과제/데이터에 맞는 알고리즘을 고르고, feature와 hyperparameter를 설정.
- **평가**: 훈련 데이터로 예측한 결과를 테스트(검증) 데이터셋 결과와 비교해 검증.
- 이 절차 전체를 자동화한 게 **MLOps**. 한 번 만들고 끝이 아니라 수집→배포 루프를 계속 돌리는 구조라는 점이 핵심.

---

## 3. 머신러닝의 종류

### 핵심 개념
- 지도학습 / 비지도학습 / 강화학습

### 상세 내용
- **지도학습(Supervised)**: 훈련 데이터 + 정답(label)을 같이 제공.
  - **분류(Classification)**: 정답 y가 이산값. 이진 분류(예/아니오) / 다중 분류. (번호판·필기체 인식 등)
  - **회귀(Regression)**: 정답 y가 연속값. (부동산 가격·기후 변화 등) 독립변수 1개 = 단순 선형 회귀, 2개 이상 = 다중 선형 회귀.
  - 대표 알고리즘: 로지스틱 회귀, 결정나무(Decision Tree), KNN, SVM, 선형 회귀.
- **비지도학습(Unsupervised)**: label 없이 x만으로 숨은 구조를 찾음. (군집화 / 차원축소) 대표: K-Means, DBSCAN, PCA. → "답이 없고, 답을 찾아가는 과정."
- **강화학습(Reinforcement)**: 에이전트가 행동(Action) → 보상(Reward)을 받으며 보상이 최대화되는 방향으로 학습. (DQN, A3C, 알파고)

---

## 4. 일반화 / 과대적합 / 과소적합

### 핵심 개념
- **일반화(Generalization)**: 훈련 데이터에서 학습한 것이 테스트 데이터에서도 통하는 상태.
- **과대적합(Overfitting)**: 훈련 데이터에만 최적화되어 새 데이터 예측력이 떨어지는, 일반화에 실패한 상태.
- **과소적합(Underfitting)**: 모델이 너무 단순해서 데이터 구조를 제대로 못 잡는 상태.

### 상세 내용
- 과대적합 처리: 훈련 데이터를 더 추가 / 정규화로 모델 복잡도 조절.
- 과소적합 처리: 파라미터 추가로 복잡도 증가 / 규제 완화.
- (그래프 직관) 모델 복잡도가 올라갈수록 **학습셋 오류는 계속 내려가지만, 테스트셋 오류는 어느 지점부터 다시 올라간다.** 그 최저점이 적절한 복잡도.

---

## 5. 주요 용어

- **데이터셋**: 행(객체/인스턴스) × 열(속성 / feature / 변수)로 구성.
- **feature(특징)**: 입력 변수(독립변수 x). 예) 부동산 면적·위치.
- **label(레이블)**: 예측 대상(종속변수 y). 예) 부동산 가격, 개/고양이.
- **model(모델)**: feature와 label의 관계를 표현한 것.
- **학습(Training)** = 모델을 만들어가는 과정 / **추론(Inference)** = 학습된 모델로 label 없는 데이터의 y를 예측.

## 6. 사이킷런(scikit-learn)

### 핵심 개념
- 대표 파이썬 ML 라이브러리. `fit` / `predict` 등 **일관된 API**를 제공.

### 상세 내용
- 전처리·하이퍼파라미터·평가·학습 알고리즘을 한 패키지로 다룸. Numpy/Scipy 기반이라 빠르지만, CPU 기반이라 대용량에선 GPU 라이브러리보다 느리다.
- 핵심 흐름: **모델 객체 생성 → `fit(X_train, y_train)` → `predict(X_test)` → `accuracy_score`로 평가.**
