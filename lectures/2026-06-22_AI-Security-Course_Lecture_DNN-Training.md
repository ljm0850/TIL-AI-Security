## 핵심 인사이트 모음

### 📅 2026-06-22

- **금요일의 의문이 오늘 강의 구조로 확인** 금요일에 "로지스틱 회귀는 경사하강법을 *안 쓰는 게 아니라*, 비용함수를 RSS 대신 Cross-Entropy로 바꾸고 거기에 경사하강법을 적용하는 것"이라고 정정했는데, 오늘 DNN 강의가 **손실함수(무엇을 줄일지)와 옵티마이저(어떻게 줄일지)를 아예 별개 섹션으로** 다뤘다. 손실함수는 예측-실제 오차를 재는 자(MSE/Cross-Entropy), 옵티마이저는 그 자를 최소로 만드는 방법(GD/Adam…). 둘은 직교하는 축이고, 어떤 손실함수든 어떤 옵티마이저로든 최적화할 수 있다.

- **퍼셉트론의 "계단함수"가 버려진 이유** 계단함수는 불연속이라 미분이 안 된다 → 역전파(미분의 연쇄법칙으로 가중치를 갱신)가 불가능하다. 그래서 DNN은 미분 가능한 sigmoid/ReLU 같은 비선형 활성화함수를 쓴다.

- **활성화함수가 "비선형"이어야 하는 이유가 결정적이다.** 선형함수(`h(x)=wx`)만 쌓으면 `w³x`처럼 결국 또 하나의 선형함수가 돼서 은닉층을 쌓은 효과가 0이 된다. 비선형을 끼워야만 층을 깊게 쌓는 의미가 생긴다. "깊이"가 힘을 갖는 건 비선형 덕분.

- **XOR → 다층 → 깊은 신경망의 동기가 한 줄로 이어진다.** 단일 퍼셉트론은 직선 하나(선형 분리)뿐이라 XOR을 못 푼다. XOR은 NAND·OR·AND 퍼셉트론을 조합(=은닉층)하면 풀린다. 이 "층을 쌓아 비선형 경계를 만든다"가 곧 DNN

- **기울기 소실/발산은 "깊은 모델일수록 취약한 학습"이라는 신호.** 역전파에서 층이 깊어질수록 미분이 곱해지며 기울기가 0으로 사라지거나(소실) 폭발한다(발산). 이건 단순한 학습 난이도 문제가 아니라, 깊은 모델의 학습이 본질적으로 불안정하다는 뜻 — 학습 과정에 개입(예: 데이터 포이즈닝)하거나 입력을 흔들었을 때 모델이 쉽게 흔들릴 여지와도 연결된다. "깊을수록 강하지만 깊을수록 다루기 까다롭다."

## 1. 다층 퍼셉트론 (MultiLayer Perceptron, MLP)

### 핵심 개념
- 단일 퍼셉트론은 결정 경계가 직선 하나라 XOR(`z = w0 + w1·x1 + w2·x2`만으로 분리 불가)을 못 푼다.
- XOR은 **NAND, OR, AND 퍼셉트론의 조합**으로 표현 가능 → 은닉층을 둔 다층 구조.

### 상세 내용
- 다항식을 쓰면 곡선을, 커널트릭처럼 구부러진 결정면을 만들 수 있다 (금요일 SVM 커널과 동일 발상).
- 입력 → (은닉: NAND·OR) → (출력: AND) 형태로 층을 쌓으면 비선형 분리가 된다.

## 2. DNN (심층 신경망, Deep Neural Network)

### 핵심 개념
- 입력층과 출력층 사이에 **은닉층 2개 이상**으로 구성된 망.
- 복잡한 **비선형 관계** 모델링이 가능 (활성화 함수로 비선형 사용).
- 효율적 학습을 위해 **오류 역전파 + 옵티마이저** 사용. 단점: 과적합, 많은 연산/긴 학습 시간.

### 상세 내용
- **순전파(Forward propagation)**: 입력층 → 은닉층 → 출력층으로 입력·처리 결과가 순차 전달. 활성화로 비선형 함수 사용. 마지막에 손실함수로 예측값(ŷ)과 실제값(y)의 차이를 구한다.
- **역전파(Back propagation)**: 손실함수로 계산된 **오차를 가중치에 반영**하기 위해 출력층 → 입력층 방향으로 가중치를 갱신. 미분의 **연쇄법칙(chain rule)** 으로 각 가중치에 대한 오차 기여도(∂L/∂w)를 구하고, 그만큼 가중치를 줄인다.
  - 가중치 갱신: `w' = w − η·(∂L/∂w)` (η = 학습률)
- **기울기 소실(Gradient Vanishing)**: 은닉층이 많으면 입력층으로 갈수록 미분이 누적 곱해지며 기울기가 0으로 사라짐.
- **기울기 발산(Gradient Exploding)**: 반대로 기울기가 커져 가중치가 폭발.

## 3. 배치(Batch)와 에포크(Epoch)

### 핵심 개념
- **배치(Batch)**: 가중치를 한 번 업데이트할 때 사용하는 데이터(Sample) 개수. (메모리 등 시스템 환경에 따라 결정)
- **에포크(Epoch)**: 전체 데이터를 1회 학습한 것. 한 에포크는 하나 이상의 배치로 구성.
- **이터레이션(Iteration)**: 단위 배치로 한 에포크를 완료하는 데 필요한 반복 횟수.

### 상세 내용
- 예: 총 데이터 1000개, 배치 100개, 에포크 5회 → 총 반복 (1000/100)×5 = 10(배치)×5(에포크) = 50회, 이터레이션 10회.
- 배치가 클수록 메모리를 많이 쓰고 연산이 느려질 수 있다.

## 4. 활성화 함수 (Activation Function)

### 핵심 개념
- 신경망에서 출력 값을 결정하는 **비선형 함수**. 선형이면 층을 쌓아도 단층과 동일(`f(x)=wx → w³x`)해서 은닉층 효과가 없고, 미분 시 상수가 나온다.

### 상세 내용
- **선형(linear)**: `h(x)=wx`. 얕은 신경망과 결과 동일 (은닉층 의미 없음).
- **계단(step)**: 음수→0, 양수→1. 불연속이라 **미분 불가** → 역전파에 못 씀 (퍼셉트론용).
- **시그모이드(sigmoid)**: 출력 0~1로 정규화. 이진 분류 출력층에 많이 씀. 편미분 최대값이 **1/4**이라 층이 쌓일수록 기울기가 0으로 수렴(Gradient Vanishing). x가 ±5 이상이면 기울기≈0.
- **tanh**: 출력 −1~1. 편미분 최대값 1이라 시그모이드보다 소실이 덜함.
- **ReLU**: `f(x)=max(0, x)`. **현재 가장 많이 채택.** 구현 단순·연산 빠름, 시그모이드의 소실 문제 해결. 단점: 음수에서 기울기 0(죽은 ReLU).
- **softmax**: 다중 분류 출력층. 출력 합=1인 확률로 정규화 → 가장 높은 확률 클래스 선택.

## 5. 손실 함수 (Loss Function)

### 핵심 개념
- 실제값과 예측값의 차이를 수치로 전달하는 함수 = 모델 성능 지표. (비용함수와 같은 말)

### 상세 내용
- **MSE**: `(1/N)Σ(y−ŷ)²`. 기본 지표지만 스케일·제곱에 의해 값이 왜곡될 수 있음.
- **RMSE**: MSE의 제곱근. 제곱으로 인한 왜곡을 완화.
- **Cross-Entropy(CEE)**: **분류 문제**에 사용. 엔트로피(불순도)가 낮을수록 발생 확률이 높다는 정보이론 기반. one-hot 인코딩과 함께 많이 씀. 이진분류=Binary CE, 다중분류=Categorical CE.

## 6. 옵티마이저 (Optimizer)

### 핵심 개념
- 손실함수가 최소가 되도록 가중치·편향(매개변수)의 최적값을 찾는 방법.

### 상세 내용
- **GD(경사하강법)**: 포물선의 최저점을 미분으로 찾아감. `θ = θ − γ·∇f(θ)`, γ=학습률(보통 0.01~0.001).
- **BGD(배치 GD)**: 전체 데이터를 한 배치로. 안정적 수렴이지만 느리고 메모리 많이 쓰고 **지역 최적(local minimum)** 에 빠질 수 있음.
- **SGD(확률적 GD)**: 매 단계 무작위 1개 데이터로 기울기 계산. 빠르고 메모리 적게 쓰며 무작위라 지역최적 탈출엔 유리하나, 경로가 불안정.
- **MSGD(미니배치 GD)**: 무작위 작은 배치 단위. BGD보다 빠르고 GPU 병렬에 유리. 배치 사이즈는 **2의 제곱수**를 많이 씀(행렬연산).
- **Momentum**: 기울기의 경향을 **관성(운동량)** 으로 누적 → 지역최적/평탄구간에서 멈추지 않고 통과. (개인 직관: 급하게 내려온 만큼의 관성을 다음 스텝에 실어, 작은 굴곡에 갇히지 않고 더 깊은 최저점을 찾는 느낌.)
- **AdaGrad**: 매개변수마다 학습률을 다르게 — 많이 변한 건 작게, 적게 변한 건 크게. 단, `G_t`가 계속 커져 학습률이 0으로 수렴하는 문제.
- **RMSProp**: AdaGrad의 학습률 소실 문제를, 최신 기울기를 지수가중이동평균으로 반영해 완화.
- **Adam**: **현재 가장 많이 사용.** Momentum + RMSProp를 동시에 적용 (관성 + 매개변수별 적응 학습률). 보통 β1=0.9, β2=0.999, ε=1e-8.
