## 핵심 인사이트 모음

### 📅 2026-06-23

- **RNN의 한 줄 정의: "이전 출력을 이번 입력에 다시 쓰는 신경망".** 지금까지 본 순방향(Feedforward) 신경망은 활성화 결과가 한쪽으로만 흘러서 과거 결과를 현재에 못 쓴다. RNN은 **이전 은닉상태를 현재 계산에 되먹임**한다. 그래서 순서가 의미를 만드는 데이터(자연어, 시계열, 동영상)에 맞는다 — "I shop in shop"의 두 shop이 품사가 다른 걸 앞 맥락으로 구분하는 식.

- **어제 배운 기울기 소실이 RNN에서 "장기 의존성 문제"로 되돌아왔다.** RNN은 시퀀스 길이만큼 같은 셀을 반복하니, 역전파 때 미분이 그 길이만큼 곱해진다 → 1보다 작은 미분이 누적되면 0으로 사라지고(소실), 1보다 크면 폭주한다. 결과적으로 **문장이 길면 앞쪽 정보(주어 등)를 잃어** 잘못 해석한다. 어제 "깊을수록 학습이 불안정"하다고 적은 게, RNN에선 "길수록 불안정"으로 같은 원리가 나타남.

- **LSTM은 "기억을 따로 관리하는 통로(Cell State)"로 그 문제를 푼다.** RNN은 단기 상태(Hidden State)만 있어 매 스텝 덮어써진다. LSTM은 여기에 **장기 상태(Cell State)** 를 추가하고, 3개의 게이트로 "무엇을 잊고(Forget) / 무엇을 새로 담고(Input) / 무엇을 내보낼지(Output)"를 조절한다.

- **GRU는 LSTM의 경량 버전 — 같은 목적, 더 적은 부품.** LSTM의 Cell+Hidden 두 상태와 3 게이트를, GRU는 **Hidden State 하나 + 2 게이트(Reset, Update)** 로 줄였다. Reset은 LSTM의 forget+input을, Update는 input+forget 역할을 통합. "복잡도를 줄여 연산을 아끼되 성능은 비슷하게"

- **순차 모델은 "로그/시퀀스 이상탐지"의 도구가 될 수 있다.** RNN/LSTM이 잘하는 건 "앞 맥락으로 다음을 예측"하는 것 = 정상 시퀀스의 패턴 학습. 보안에서 접속 로그·명령어 시퀀스·네트워크 트래픽 같은 시계열에서 "정상 흐름을 벗어난 지점(이상)"을 잡는 데 같은 구조를 쓸 수 있다. 분류·회귀에 이어 "순서"를 다루는 도구가 생기면서 보안에서 다룰 수 있는 데이터 형태가 넓어진 셈.

## 1. RNN (순환 신경망, Recurrent Neural Network)

### 핵심 개념
- 이전 과정의 결과(h_{t-1})를 이번 계산에 사용 → **재귀적(순환)** 으로 동작.
- 순서가 의미를 결정하는 데이터(자연어, 시계열, 동영상)에 적합.
- `h_t = tanh(w_h·h_{t-1} + w_x·x_t + b)` — 이전 은닉상태·현재 입력에 각각 가중치를 곱하고 편향을 더해 tanh 적용.

### 상세 내용
- **입력/출력 크기 조합**으로 다양한 작업: 문장→이진분류(스팸), 문장→다중분류(감정/의도), 문장→문장(번역), 긴 문장→짧은 문장(요약).
- **장기 의존성 문제(Long-Term Dependencies)**: 시퀀스가 길면 출력단으로 갈수록 처음 정보를 잃음. 역전파 중 **기울기 소실**(미분<1 누적→0) / **기울기 폭주**(미분>1 누적→∞)가 원인.

## 2. LSTM (장단기 메모리, Long Short-Term Memory)

### 핵심 개념
- RNN의 기울기 소실(장기 의존성)을 완화하기 위해, 단기 상태 외에 **장기 상태(Cell State)** 를 추가한 구조.
- **Hidden State(h_t)**: 단기 보관, 매 스텝 계속 업데이트. **Cell State(C_t)**: 장기 보관, 업데이트될 수도/안 될 수도.

### 상세 내용
- **3개의 게이트로 Cell State를 관리**:
  - **Forget Gate**: 이전 Cell State에서 **무엇을 지울지** 결정. h_{t-1}을 sigmoid(0~1)로 변환해 C_{t-1}에 곱함 (0이면 제거).
  - **Input Gate**: 새 정보를 **무엇을 담을지** 결정. sigmoid×tanh로 Cell State에 더함.
  - **Output Gate**: Cell State에서 **무엇을 내보낼지** 결정. 다음 hidden state로 전달.
- Cell State 관리 때문에 구조가 복잡하고 연산량이 많다.

---

## 3. GRU (Gated Recurrent Unit)

### 핵심 개념
- LSTM의 복잡한 구조·많은 파라미터를 개선한 경량 모델. 성능은 유사, 연산은 절약.

### 상세 내용
- **상태**: Hidden State 하나 (LSTM의 Cell+Hidden을 하나로).
- **게이트 2개**:
  - **Reset Gate**: LSTM의 forget+input 기능 통합. 이전 상태를 얼마나 반영할지 계산.
  - **Update Gate**: 이전 상태(1−z_t)와 현재 후보 상태(z_t)의 적용 비율 결정.
