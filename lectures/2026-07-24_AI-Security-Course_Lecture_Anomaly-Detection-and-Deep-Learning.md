## 핵심 인사이트 모음

### 📅 2026-07-24

- **AI 보안 시스템은 ML 한 층으로는 안 되고 여러 층으로 겹쳐 봐야 할 것 같다.** 오늘까지 본 탐지 방식이 텍스트·URL·PE·네트워크·행동으로 나뉘는데, 각각 보는 각도가 달라서 하나가 놓친 걸 다른 하나가 잡는 구조가 자연스럽다.
- **내부자 위협에는 시그니처가 없다. 정상 권한으로 벌어지기 때문이다.** 그래서 "공격을 학습한다"가 아니라 "정상을 학습하고 거기서 벗어남을 찾는다"로 접근이 뒤집힌다. 비정상 샘플이 적을 때도 쓸 수 있다는 점이 매력적이다.
- **정상 패턴에서 벗어남을 찾는 문제는 보안 밖에서도 구조가 같다.** 품질 검증(QC) 같은 데도 그대로 쓸 수 있고, 프롬프트 인젝션 시도 탐지에도 적용해 볼 만하다.
- **MLP는 특징 공학의 부담을 덜어주는 대신 판단 근거가 흐려진다.** 로지스틱 회귀의 계수나 랜덤포레스트의 특징 중요도처럼 "무엇 때문에 그렇게 봤는지"를 바로 꺼내 보기 어렵다.

## 1. 비지도 학습과 내부자 위협

### 핵심 개념
- 내부자에 의한 **기밀 데이터 유출(Exfiltration)·시스템 파괴(Sabotage)·산업 스파이(Espionage)**는 정상 권한을 가진 계정으로 수행되는 경우가 많아 명확한 공격 시그니처가 없다.
- 따라서 정상 행동 패턴을 학습한 뒤 거기서 벗어나는 징후를 찾는 **비지도 학습 기반 이상 탐지**를 쓴다.

### 상세 내용

| 위협 유형 | 행동 흔적 |
|---|---|
| Exfiltration (유출) | 야간·주말 접속, 민감 파일 대거 접근, 대용량 업로드, USB 반복 삽입 |
| Sabotage (파괴) | 새벽 활동, 권한 상승 반복 시도, 접근 실패 폭증 |
| Espionage (스파이) | 비교적 조용함. 민감 파일 집중 접근 + 외부 이메일·대용량 첨부 |

## 2. Isolation Forest

### 핵심 개념
- 거리·밀도를 계산하는 기존 이상 탐지와 달리, 데이터를 **무작위로 분할해 고립(Isolation)시키는** 트리 구조로 정상과 이상치를 구분한다.

### 상세 내용
- **동작 원리**: 무작위로 특징과 분할 값을 골라 트리를 만들 때, 정상 데이터는 밀집 영역에 있어 고립되기까지 분할이 많이 필요하다(경로 길이 김). 이상치는 희소한 위치에 있어 적은 분할만으로 떨어져 나온다(경로 길이 짧음).
- **이상 점수(Anomaly Score)**: 여러 Isolation Tree에서 고립될 때까지의 **평균 경로 길이**로 계산. 경로가 짧을수록 이상 점수가 높고, 1에 가까울수록 이상치일 가능성이 크다.

## 3. MLP (Multi-Layer Perceptron)

### 핵심 개념
- 로지스틱 회귀·랜덤포레스트 같은 전통 ML은 특징(Feature)을 사람이 직접 추출·정제해야 하는 한계가 있다. MLP는 **입력층 → 은닉층 → 출력층** 구조로 비선형 관계를 스스로 학습한다.

### 상세 내용
- 각 뉴런은 이전 층 입력에 가중치를 곱하고 편향을 더한 뒤 활성화 함수로 다음 층에 신호를 전달한다.
  - `z = Wx + b`
  - `a = σ(z)` (σ는 ReLU 등 비선형 활성화 함수)

---

## 4. 과적합 방지 및 안정화

| 기법 | 내용 |
|---|---|
| Batch Normalization | 미니배치 단위로 각 층의 입력 분포를 평균 0·분산 1로 정규화. 내부 공변량 변화(Internal Covariate Shift)를 줄여 학습 속도를 높이고 초기화 민감도를 낮춘다 |
| Dropout | 학습 중 은닉층 뉴런 일부를 확률적으로 비활성화. 특정 뉴런 의존도를 줄여 일반화 성능을 높인다 |

## 5. 다중 클래스 분류

### 핵심 개념
- 이진 분류(정상/공격)만으로는 부족하다. 실제 보안 관제에서는 **공격 유형을 세분화해야 대응 정책을 세울 수 있으므로** 다중 클래스 분류가 필요하다.

### 상세 내용
- **Softmax**: 출력을 각 클래스에 속할 확률로 변환하고, 전체 합이 1이 되도록 정규화.
  - `P_i = e^(z_i) / Σ(j=1..K) e^(z_j)` (z_i는 각 클래스에 대한 출력값 logit)
- **손실 함수**: 정답 레이블과 예측 확률 분포의 차이를 재는 **교차 엔트로피 손실(Categorical Cross-Entropy)**.

> ※ 강의 자료 슬라이드 16쪽에 "ex03 실습에서는 네트워크 트래픽을 2개 클래스로 분류"라고 되어 있으나, 네트워크 이진 분류는 **ex04**다(ex03은 악성코드 PE 분류). 7/23 자료의 챕터 번호 밀림에 이은 두 번째 표기 불일치로, 실습 파일 번호 기준으로 정리했다.
