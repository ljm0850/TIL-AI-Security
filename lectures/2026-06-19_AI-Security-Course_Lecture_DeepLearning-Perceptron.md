## 핵심 인사이트 모음

### 📅 2026-06-19

- **딥러닝은 "회귀를 쌓은 것"이라는 그림이 잡혔다.** 뉴런 하나 = `f(x) = w0 + w1·x1 + ...`(선형회귀) + 활성화 함수로 Yes/No를 내는 장치. 결국 오늘 배운 로지스틱 회귀(선형결합 → 시그모이드 → 분류)가 뉴런 하나의 정체였다. 이걸 층층이 연결하고(은닉층) 깊게 쌓은 게 DNN. "새 개념을 기존 것과 연결"하는 입장에서 보면 딥러닝은 완전히 새로운 게 아니라 회귀 + 활성화의 반복 구조.

- **얕은 신경망으로도 이론상 대부분 학습 가능한데, 실제로는 깊게 쌓은 쪽이 성능이 좋다.** 그래서 은닉층 2개 이상(깊은 신경망)을 DNN이라 부르고 그 학습을 딥러닝이라 한다. "이론적 가능 ≠ 실용적 효율"이라는 게 흥미로움.

- **퍼셉트론의 한계(XOR)가 신경망 역사의 분기점이었다.** 퍼셉트론은 직선 하나로 영역을 가르는 선형 분류기라, AND·OR·NAND는 풀어도 XOR(선형 분리 불가)은 못 푼다. 강의 타임라인에서 이 XOR 문제가 "AI 겨울(Dark Age)"로 이어짐

- **AI 보안 관점 — 딥러닝의 "블랙박스" 성질이 곧 위험 표면(attack/audit surface)이다.** 딥러닝은 결과 도출 과정을 설명하기 어려워서 블랙박스라 불리고, 그래서 XAI(설명 가능한 AI) 연구가 붙는다. 보안에서 이건 두 가지로 읽힌다: (1) 모델이 왜 그 판단을 했는지 감사하기 어려워 오탐/우회를 잡기 힘들고, (2) "스스로 특징을 학습"하는 만큼 학습 데이터를 오염시키면(데이터 포이즈닝) 사람이 눈치채기 어렵다. 오전에 본 선형/트리 모델의 해석 가능성과 정반대 성질.

## 1. 딥러닝(Deep Learning) 개요

### 핵심 개념
- 인공신경망(ANN, Artificial Neural Network)에서 발전한 형태. 뇌의 뉴런과 비슷한 구조로 정보의 입/출력 계층과 뉴런을 이용해 학습.
- 구조: **[ Input layer ] - [ Hidden layer ] - [ Output layer ]**
  - 은닉층 1개 = 얕은(Shallow) 신경망 / 2개 이상 = 깊은(Deep) 신경망 = **DNN(심층신경망)**.
  - 각 layer에는 여러 개의 뉴런(노드, 유닛)이 존재.
  - 모든 계층의 뉴런이 이전 계층의 모든 뉴런과 연결되면 **전결합층(FC, Dense layer)**.

### 상세 내용
- 대표 알고리즘: **CNN**(합성곱, 이미지) / **RNN**(순환, 시퀀스).
- 신경망 역사 흐름(강의 타임라인): 퍼셉트론(1957) → ADALINE → XOR 문제 → AI 겨울 → 다층 퍼셉트론+역전파(1986) → SVM(1995) → 딥러닝 부흥(2006~).

## 2. 딥러닝의 특징

### 핵심 개념
- **데이터가 많을수록 성능이 계속 좋아진다.** 일반 머신러닝은 데이터가 일정 수준을 넘으면 성능 향상이 정체되는 것과 대조.
- **특징(feature)을 스스로 학습**, 라벨 없이도 학습 가능.

### 상세 내용
- (내 메모) 그래도 전처리를 거친 데이터를 써야 효과가 좋다 — "스스로 학습"이 "전처리 불필요"를 뜻하진 않음.
- 학습 데이터에 따라 재학습이 필요해 **실시간 학습은 불가능**.
- 결과 도출 과정을 설명하기 힘든 **블랙박스(Black Box)** → 최근 **XAI(eXplainable AI)** 연구 활발.
- 주로 이미지·비디오·음성 같은 **비정형 데이터**에 많이 쓰인다.

## 3. 퍼셉트론(Perceptron)

### 핵심 개념
- 1957년 로젠블라트가 고안. 입력 벡터를 **이진 분류**하기 위한 선형 알고리즘(함수의 합성).
- 구성: 입력(x) · 가중치(w) · 활성화 함수 · 출력.
  - `f(x) = w0 + w1·x1 + w2·x2 + ... + wn·xn` ← 선형회귀와 같은 식
  - `h(x) = 0 (f(x) ≤ θ) / 1 (f(x) > θ)`, θ = 임계값

### 상세 내용
- **활성화 함수**: 선형결합 결과를 특정 범위/형태로 변환하는 함수. 퍼셉트론에서는 **계단(step) 함수**를 써서 임계값 비교로 0/1을 낸다.
- **논리 연산 구현** (가중치·편향만 바꾸면 다른 게이트가 됨):

  | 연산 | w0 | w1, w2 | 직관 |
  |---|---|---|---|
  | AND | −1 | 0.6 | 둘 다 1일 때만 합이 임계 초과 |
  | OR | −0.5 | 0.6 | 하나만 1이어도 임계 초과 |
  | NAND | +1 | −0.6 | AND의 반대(가중치 부호 반전) |

- **XOR 문제**: 단일 퍼셉트론은 직선 하나로만 영역을 가르므로, 선형 분리가 불가능한 XOR은 못 푼다. → 다층 구조(은닉층)로 넘어가는 동기.
