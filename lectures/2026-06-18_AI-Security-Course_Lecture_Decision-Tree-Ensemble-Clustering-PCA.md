## 핵심 인사이트 모음

### 📅 2026-06-18

- **결정트리는 SVM과 반대 방향으로 복잡도를 다룬다.** SVM은 차원을 올려서 선형 분리를 가능하게 하고, 결정트리는 질문의 depth를 늘려서 분류한다. 두 알고리즘 모두 "지금 이 공간에서 분리가 안 되면 다른 방식으로 공간을 재구성한다"는 공통 철학이 있다. 접근 방향이 다를 뿐이다.

- **지니 불순도를 보면서 우선순위 큐가 생각났다.** 불순도가 제일 낮은 조건을 루트 노드로 선택하는 과정이 우선순위 큐로 최솟값을 꺼내는 패턴과 구조적으로 같다. ML 알고리즘 안에서 자료구조 개념이 이렇게 연결될 줄은 몰랐다.

- **앙상블의 핵심은 "다양성"이다.** 단일 모델이 과적합되는 이유는 한 가지 시각으로만 데이터를 보기 때문이다. 배깅은 데이터에 다양성을 주고(부트스트랩), 부스팅은 이전 모델이 틀린 곳에 다음 모델이 집중하게 한다. 두 방식 모두 "약한 학습기들의 협업"이라는 점은 같지만 협업 방식이 병렬(배깅) vs 순차(부스팅)로 다르다.

- **하이퍼파라미터 탐색에 이진탐색을 쓰면 어떨까?** GridSearchCV가 격자 전체를 탐색하는 것을 보고 든 생각이다. 최적값이 단조적으로 존재하는 파라미터라면 이진탐색 방식으로 mid값을 계속 좁혀가는 게 효율적일 것 같다. 단, 실전에서는 파라미터 반응이 단조적이라는 보장이 없어서 적용이 어려울 수 있다.

- **PCA는 "디테일을 버리고 큰 특징만 남기는" 전처리다.** 차원이 너무 많으면 모델이 노이즈까지 학습해서 일반화가 어려워진다. PCA는 데이터를 투영할 때 분산이 최대가 되는 축을 찾아서 핵심 정보는 유지하면서 차원을 줄인다. 8×8 손글씨(64차원)를 5×5(25차원)로 줄여도 복원 이미지가 식별 가능한 것이 인상적이었다. 단, 압축된 특징은 원래 의미를 잃어서 설명이 어렵다는 트레이드오프가 있다.

## 1. 결정 트리 (Decision Tree)

### 핵심 개념

조건 판단 노드로 구성된 이진 트리를 이용해 분류 또는 회귀 문제를 푸는 지도학습 알고리즘. 각 노드에서 "이 조건이 참인가?"를 묻고 Yes/No로 분기한다.

### 구성 요소

| 용어 | 설명 |
|---|---|
| 루트 노드 | 트리 최상위, 불순도를 가장 많이 줄이는 조건을 선택 |
| 내부 노드 | 조건 판단이 이루어지는 중간 노드 |
| 리프 노드 | 자식 노드가 없는 최종 분류 결과 노드 |
| 깊이(Depth) | 루트에서 리프까지의 길이 |

### 알고리즘

불순도를 단계별로 줄여가며 혼합도가 사라질 때까지 반복 분기. scikit-learn은 CART 알고리즘 사용 (분류·회귀 모두 가능, 이진 분기, 지니 계수 기본).

### 불순도 측정 방법

**지니 불순도 (Gini impurity)**

```
Gini = 1 - Σ(Pj²)
```

- Pj: j 클래스에 속할 확률
- 값이 0 → 완전 순수 (한 클래스만 존재)
- 값이 클수록 불순도 높음 (여러 클래스가 섞임)
- scikit-learn 기본값

예시 (자동차/비행기 6개):
- 날개 기준: `1 - ((3/6)² + (3/6)²) = 0.5`
- 바퀴 기준: `1 - ((4/6)² + (2/6)²) = 0.44` → 바퀴가 더 좋은 분기 조건

**정보 이득 (Information Gain)**

```
IG(T, X) = E(T) - E(T|X)
```

- 분기 전후의 엔트로피 차이. 클수록 좋은 조건.
- 엔트로피: 무질서도. 순수할수록 0, 완전 혼합이면 1.
- `E = -Σ(Pi * log₂(Pi))`

### 하이퍼파라미터

| 파라미터 | 설명 | 과적합 방지 |
|---|---|---|
| `max_depth` | 트리 최대 깊이 | 낮출수록 과적합 감소 |
| `min_samples_split` | 내부 노드 분할 최소 샘플 수 | 높일수록 과적합 감소 |
| `min_samples_leaf` | 리프 노드 최소 샘플 수 | 높일수록 과적합 감소 |
| `criterion` | 분할 기준 (`gini` 기본, `entropy`) | - |

### 특징

- 결과 시각화·설명이 쉬움 (`tree.plot_tree()`)
- 연속형·범주형 데이터 모두 적용 가능
- 데이터 전처리(스케일링) 영향을 덜 받음
- **과대적합 발생 확률이 높음** — 앙상블의 필요성으로 이어짐

## 2. 앙상블 (Ensemble)

### 핵심 개념

여러 분류기를 학습시키고 결과를 결합하여 단일 모델의 한계를 극복하는 기법. 과적합이 문제면 배깅, 성능이 문제면 부스팅.

### 배깅 (Bagging)

**부트스트랩 애그리게이팅(Bootstrap Aggregating)**의 약자.

- **부트스트랩**: 원본 데이터에서 중복을 허용하여 여러 샘플 셋을 만든다. 각 모델이 다른 데이터로 학습 → 다양성 확보
- **집계(Aggregation)**: 각 모델의 예측을 투표(Voting)로 결합
- 대표 알고리즘: **랜덤 포레스트(Random Forest)**
- 병렬 처리 가능

**보팅(Voting)**

| 방식 | 설명 |
|---|---|
| 하드 보팅 | 다수결 (가장 많이 예측된 클래스) |
| 소프트 보팅 | 예측 확률 평균 → 더 정교함, **권장** |

**랜덤 포레스트**

- 결정트리를 배깅에 적용한 알고리즘
- `n_estimators`: 사용할 결정트리 수
- 결정트리의 설명 가능성 + 배깅의 일반화 = 실용적 균형

### 부스팅 (Boosting)

이전 분류기가 틀린 데이터에 가중치를 높여 다음 분류기가 집중 학습. **순차적** 방식.

약한 학습기(Weak Learner)를 모아 강한 학습기(Strong Learner)를 만드는 방법.

**AdaBoost**
- 각 약한 학습기의 오류에 따라 가중치 조정
- `H(x) = Σ ωᵢhᵢ(x)` (강한 학습기 = 약한 학습기들의 가중합)

**GBM (Gradient Boosting Machine)**
- 가중치 수정 값을 경사 하강법(Gradient Descent)으로 계산
- 오차함수(Loss function)를 지정할 수 있어 유연함
- 성능은 좋지만 학습이 오래 걸림

**XGBoost (eXtreme Gradient Boosting)**

GBM 기반이지만 실전에서 가장 많이 쓰이는 알고리즘 중 하나.

- 병렬 수행으로 GBM 대비 속도 빠름
- 과적합 규제 기능 내장 (L1/L2 정규화)
- 가지치기(Tree Pruning): 이득 없는 분할 제거
- 조기 종료(Early Stopping) 지원
- scikit-learn 호환 래퍼 클래스 제공

```python
from xgboost import XGBClassifier
xgb_clf = XGBClassifier(random_state=15, eval_metric='mlogloss')
xgb_clf.fit(X_train, y_train)
```

주요 하이퍼파라미터:

| 파라미터 | 설명 |
|---|---|
| `n_estimators` | 약한 학습기 수 |
| `learning_rate` | 학습률 (0.01~0.2 권장) |
| `max_depth` | 트리 최대 깊이 |
| `gamma` | 리프 분리 최소 손실 감소량 |
| `reg_lambda` | L2 정규화 |
| `reg_alpha` | L1 정규화 |

### 나이브 베이즈 (Naive Bayes)

강의에서 간략히 소개만 됨. 베이즈 정리의 조건부 확률을 이용한 분류 알고리즘. 스팸 분류, 텍스트 분류에 주로 사용. 관심 있으면 별도로 찾아볼 것.

## 3. 군집화 — K-Means

### 핵심 개념

레이블 없는 데이터를 거리 기반으로 k개 그룹으로 묶는 비지도학습. 같은 군집 내 거리는 최소, 군집 간 거리는 최대가 되도록.

### 실행 과정

1. k개의 중심점을 임의 위치에 지정
2. 중심점과 가장 가까운 데이터들을 해당 군집에 할당
3. 군집 내 데이터들의 평균으로 중심점 이동
4. 군집 소속이 변경되지 않거나 중심이 움직이지 않을 때까지 2~3 반복

### 중심 초기화 방법

| 방법 | 설명 | 단점 |
|---|---|---|
| random | 무작위 위치 지정 | 중심이 몰릴 수 있음 |
| k-means++ | 첫 중심에서 가장 먼 점을 다음 중심으로 | 더 안정적, 권장 |

### 최적 k 탐색

**엘보우 기법 (Elbow Method)**: k를 1~10으로 변화시키며 Inertia(군집 내 거리 제곱합) 변화를 시각화. 기울기가 꺾이는 지점이 최적 k.

**실루엣**: k별 평균 실루엣 계수를 비교하여 군집 품질 확인.

```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_samples

inertias = []
silhouettes = []
for i in range(1, 11):
    kms = KMeans(n_clusters=i, init='k-means++', random_state=15)
    pred = kms.fit_predict(X)
    inertias.append(kms.inertia_)
```

## 4. 주성분 분석 (PCA)

### 핵심 개념

고차원 데이터를 저차원으로 축소하는 차원 축소 기법. 데이터를 직선(축)에 투영할 때 **분산이 최대화**되는 방향을 주성분(PC)으로 삼는다.

### 알고리즘

1. 데이터 중심점을 원점(0, 0)으로 이동
2. 분산이 최대화되는 방향을 PC1으로 설정
3. PC1과 직교하는 방향 중 분산이 최대인 방향을 PC2로 설정
4. 이를 반복하여 원하는 차원 수만큼 주성분 확보
5. 선택한 주성분 축으로 데이터 투영 → 차원 축소

내부적으로 공분산 행렬의 고유값·고유벡터를 이용.

### 특징

- 노이즈 영향력 감소 (주요 특징만 남기므로)
- 과적합 확률 감소
- 학습 속도 향상, 메모리 절약
- 고차원 데이터 시각화에 유용 (3차원 이하로 축소)
- **단점: 압축된 특징은 원래 의미를 잃어 결과 설명이 어려움**

```python
from sklearn.decomposition import PCA

pca = PCA(n_components=25)          # 64차원 → 25차원
X_reduced = pca.fit_transform(X)    # 차원 축소
X_recovered = pca.inverse_transform(X_reduced)  # 복원 (손실 있음)
```

실습에서 8×8 손글씨(64차원)를 5×5(25차원)로 줄였을 때 차원축소본은 흐릿하지만 복원본은 원본과 유사하게 복구됨.
