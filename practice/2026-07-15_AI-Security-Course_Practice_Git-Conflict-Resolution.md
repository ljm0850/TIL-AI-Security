## 실습 개요
- **목표**: 같은 파일 같은 줄을 두 브랜치에서 다르게 수정해 충돌을 재현·해결하고, 되돌리기/hotfix 흐름을 복습.

---

## 진행 과정 (흐름만)

- **충돌 재현(Step 17~18)**: main과 `conflict-test`에서 `team.md`의 같은 줄을 각각 DevOps팀 / MLOps팀으로 수정 → `git merge` 시 `CONFLICT (content)`.
- **마커 해결(Step 19)**: `<<<<<<< HEAD` / `=======` / `>>>>>>>` 마커를 직접 편집해 최종 내용 결정 → `git add` → 병합 커밋. 마커 잔존 여부는 grep으로 확인.
- **되돌리기(Step 20)**: `git restore --staged`(스테이징만 취소, 파일 내용은 유지), `git commit --amend`(push 전에만 — 직전 커밋 메시지 교체).
- **pull 충돌(Step 21)**: 원격·로컬이 같은 줄을 각각 수정 → `git pull --no-rebase` 시 충돌 → 마커 해결 → 커밋 → push.
- **hotfix(선택)**: main에서 `hotfix/` 브랜치 분기 → 수정 → main에 fast-forward 병합 → 브랜치 정리.
