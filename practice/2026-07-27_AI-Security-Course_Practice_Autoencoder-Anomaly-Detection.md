## 느낀 것 / 배운 것

### 📅 2026-07-27

- **오토인코더가 "정상만 학습한다"는 게 강점이자 약점이었다.** 공격 라벨을 안 보고 "정상과 얼마나 다른가"만 재기 때문에, 정상처럼 생긴 공격(Brute Force, 느린 침투)에는 원리상 약하다. 7/24에 적었던 "프롬프트 인젝션 탐지에 쓸 수 있을까"에 조건이 붙는다 — 티 나게 다른 인젝션은 잡아도, 정상 요청처럼 위장한 건 못 잡는다.

## 실습 개요
- **목표**: CICIDS 모방 데이터로 **정상 트래픽만** 학습한 오토인코더를 만들고, 재구성 오차로 공격(DDoS·Brute Force·침투)을 이상치로 탐지한다.
- **방법**: Keras 대칭형 오토인코더(8→4→2→4→8) + MinMax 정규화 + 재구성 오차 임계값.

---

## 진행 과정

```
Step 1. 데이터 생성   # make_cicids() → 정상 3000 / 공격 500 (20개 특징)
                     # 공격 = DDoS / Brute Force / Infiltration
Step 2. 특징 선택      # 20개 중 8개만 사용 (SELECTED_INDICES)
Step 3. 데이터 분리    # ★정상만 학습: 학습 2100 / 검증 450 / 정상테스트 450
                     #   공격 500은 학습에 일절 넣지 않음 (테스트에만)
Step 4. 정규화        # MinMaxScaler (학습 데이터에만 fit)
Step 5. 모델          # 인코더 8→4→2(latent) → 디코더 2→4→8(sigmoid)
                     # loss=MSE, 입력=타깃 (자기 재구성)
Step 6. 학습          # epochs=100, EarlyStopping(patience=10)
Step 7. 재구성 오차    # 정상 vs 공격의 MSE 분포 비교
Step 8. 임계값 실험    # 검증 데이터의 95/99/99.9 백분위로 임계값 설정
Step 9. 신규 플로우 3건 판정
```

**실제 출력 (seed=42 고정)**
```
데이터 생성: 정상=3000  공격=500
사용 특징(8개): flow_duration, fwd_packet_len_mean, bwd_packet_len_mean,
               flow_bytes_per_sec, flow_packets_per_sec, flow_iat_mean,
               syn_flag_count, rst_flag_count

재구성 오차(MSE) 분포
  정상 (학습):   평균=0.04612   max=0.22504
  정상 (검증):   평균=0.04767   max=0.17659
  정상 (테스트): 평균=0.04701   max=0.22336
  공격:          평균=180.889   max=1231.207   ← 정상보다 압도적으로 큼

임계값별 탐지 성능
  임계값 전략           임계값     Precision   Recall     F1
  95th pct (FP 허용)    0.10052    0.9531     0.8940    0.9226
  99th pct (균형)       0.15400    0.9906     0.6340    0.7732
  99.9th pct (FP 최소)  0.17422    0.9906     0.6340    0.7732

최종 임계값 0.15400 (AUC-ROC 0.9827)
              precision  recall  f1-score  support
       정상      0.71     0.99     0.83      450
       공격      0.99     0.63     0.77      500

신규 플로우 판정
  정상 웹 브라우징        → 정상     (오차 0.042)
  DDoS 공격               → 공격 탐지 (오차 466.34)
  느린 침투 공격          → 공격 탐지 (오차 16.51)
```

**추가 확인 (공격 유형별로 뜯어봄)**
```
공격 유형별 재구성 오차(MSE) 평균 / 최소
  DDoS         : 평균=533.5   min=18.55   ← 정상과 완전히 다름
  Brute Force  : 평균=  0.205 min= 0.092  ← 정상(0.047)과 거의 안 겹침
  Infiltration : 평균= 15.04  min= 0.061

임계값(99th=0.186) 미만으로 놓친 공격 85/500
  DDoS 0/166  |  Brute Force 65/166  |  Infiltration 20/168
  → 미탐은 전부 '정상처럼 생긴' 공격에서 나온다
```

## 결과 / 산출물
- 정상 트래픽만으로 학습한 오토인코더와 재구성 오차 분포.
- 임계값 전략 3종(95/99/99.9th)별 Precision·Recall·F1 비교표.
- 공격 유형별 미탐 분석 → DDoS는 완벽 탐지, Brute Force가 최대 약점.

## 잘 된 것 / 안 된 것

| 잘 된 것 | 안 된 것 |
|---|---|
