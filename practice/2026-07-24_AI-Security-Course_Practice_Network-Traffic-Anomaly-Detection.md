## 느낀 것 / 배운 것

### 📅 2026-07-24

- **특징 중요도는 어제보다 고르게 퍼졌다.** ex03은 엔트로피 하나가 0.387로 압도적이었는데, 여기는 1위 `serror_rate`가 0.222고 상위 8개가 0.07~0.22에 분포한다. 특징을 14개 넣으니 판단 근거가 분산된 것으로 보인다.
- **공격 유형마다 남기는 흔적이 다르다. 도메인 지식의 중요성** DoS는 응답 없는 대량 연결, Probe는 넓게 훑는 짧은 연결, R2L은 로그인 실패 반복. 같은 '공격' 라벨이어도 통계적 모양이 다르다.

## 실습 개요
- **목표**: 네트워크 플로우 통계로 유입 트래픽이 정상인지 공격인지 분류하는 이진 분류 모델 구축.
- **방법**: KDD Cup 99 특징 기반 시뮬레이션 데이터 + `RandomForestClassifier`.

---

## 진행 과정

```
Step 1. 데이터 생성   # generate_traffic_data(n_normal=300, n_attack=150)
                     # 공격은 DoS / Probe / R2L 3유형으로 1/3씩 분기 생성
Step 2. 전처리        # protocol_type(tcp/udp/icmp) → LabelEncoder로 인코딩
Step 3. 특성 선택      # 14개 특징 사용 (duration ~ dst_host_count)
Step 4. 분할·학습      # test_size=0.2, stratify / RF(n=100, max_depth=10, balanced)
Step 5. 평가          # classification_report + confusion_matrix
Step 6. 특징 중요도
Step 7. 신규 트래픽 4건 판정
```

**실제 출력 (np.random.seed(42) 고정)**
```
총 데이터 수: 450개   정상 300 / 공격 150
학습데이터: 360개 | 테스트데이터: 90개

              precision    recall  f1-score   support
          정상      1.00      1.00      1.00        60
          공격      1.00      1.00      1.00        30
    accuracy                           1.00        90

혼동행렬
  [[60  0]
   [ 0 30]]

공격 탐지 핵심 특징 (중요도 순)
  serror_rate   0.222 | src_bytes  0.142 | hot        0.137 | dst_bytes 0.103
  srv_count     0.094 | logged_in  0.082 | count      0.070 | duration  0.068

신규 트래픽 판정
  일반 웹 브라우징        → 정상 (공격 확률 6.0%)
  DoS 공격 의심           → 공격 (100.0%)
  포트 스캔 의심          → 공격 (100.0%)
  브루트포스 로그인 의심   → 공격 (100.0%)
```

## 결과 / 산출물
- 정상/공격 트래픽 450건 데이터셋과 랜덤포레스트 이진 분류기.
- 특징 중요도 순위 → SYN 에러율·바이트 수·hot이 판별 축.
- 신규 트래픽 4건에 대한 공격 확률 판정.
