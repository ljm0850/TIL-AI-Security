## 진행 과정

### Step 1. 주제 설정

| 구분          | 내용                                              |
| ------------- | ------------------------------------------------- |
| **발주 주제** | 인공지능 사관학교 입교생들 간의 정보교류가 필요해 |
| **수주 주제** | 고령층 키오스크 도우미                            |

### Step 2. 1차 질문 — 초기 인사이트 도출

팀원들의 실제 경험에서 나온 초기 인사이트:

- 부모님·조부모님이 키오스크 사용을 어려워하신다
- **스마트폰 경험 자체가 없는 경우**도 고려해야 함 → "터치 방법을 모른다"는 수준을 넘어선 문제일 수 있음

### Step 3. 해결 방향에 대한 의문 제기

1차 인사이트를 바탕으로 세 가지 방향이 경합:

- **키오스크 자체 개선**
- **자연어 기반 사용 가이드 SW** 개발
- **자녀가 부모·조부모께 가르칠 때 활용할 수 있는 테스트 모델 및 가이드** 제공

> 문제의 본질이 '고령층 본인의 사용 어려움'인지, '가르쳐드리는 과정의 어려움'인지를 아직 특정하지 못한 상태 → 2차 질문 필요

### Step 4. 2차 질문 — 팀 인터뷰

| 질문                                                        | 인사이트                                                     |
| ----------------------------------------------------------- | ------------------------------------------------------------ |
| 부모님·조부모님은 키오스크에서 무엇을 가장 힘들어 하셨나요? | 디지털 기계 자체에 대한 낯섦, UI 전반이 어렵게 느껴지심      |
| 사용 방법을 설명할 때 어떤 점이 가장 힘들었나요?            | **터치 자체가 낯설고 어려우심** — 말로 안내하고 누르는 행위를 최소화하는 방향으로 대처했음 |
| 키오스크로 주제를 정한 이유는?                              | 통신사·데이터 없이 다니시는 경우가 많음 (스마트폰 미소지) → 심부름 경험에서 직접 체감한 문제 |

## 느낀 것 / 배운 것

- 1차 질문만으로는 문제 방향이 여러 갈래로 나뉘었음. 질문을 거듭할수록 문제가 구체화되는 과정을 직접 체감 — 강의에서 이론으로만 들을 때와 느낌이 달랐다.
- "터치 자체가 낯설다"는 답변은 단순 UI 문제가 아니라 **디지털 경험 자체의 부재**라는 더 깊은 Pain Point를 시사함.
- 해결 대상이 '고령층 본인'인지 '가르쳐드리는 자녀'인지에 따라 솔루션 방향이 완전히 달라짐 → **페르소나 설정이 먼저라는 것**을 몸으로 이해함.

### Step 6. 페르소나 작성 및 채택

세 가지 페르소나 시안을 작성하고 하나를 채택함.

**페르소나 1 — 미채택**

- 키오스크가 있는 가게 자체를 기피하는 유형
- Pain: 자영업 감소로 단골 가게 사라짐 → 새 가게 가야 하는데 키오스크 때문에 불편 (생존의 문제)

**페르소나 2 — 미채택**

- 배우려 해도 매번 물어봐야 하는 유형
- Pain: 반복 질문으로 자존감 하락

**페르소나 3 — 채택 ✅**

> 퇴직 후 혼자 외출이 잦아진 70대 먹구름 씨.  
> 키오스크 사용이 불편하지만 배울 의지는 없음. 직원을 찾거나 옆 청년에게 대신 주문을 부탁함.

| 항목        | 내용                                                         |
| ----------- | ------------------------------------------------------------ |
| 이름 / 나이 | 먹구름 (70대, 퇴직)                                          |
| 상황        | 퇴직 후 홀로 외출 잦아짐. 키오스크 불편하지만 배울 의지 없음 |
| Says        | "요즘엔 매장에 사람이 없어, 나같은 사람들은 어떻게 주문하라는거야" |
| Thinks      | 말로 하면 다 해결됐는데 키오스크는 주문이 너무 불편하다      |
| Does        | 직원을 찾거나 옆 청년에게 대신 주문 부탁                     |
| Feels       | 키오스크 매장에 대한 짜증, 기술에 대한 짜증                  |
| Pain        | 키오스크 없는 매장만 선택 → 선택폭 축소                      |
| Gain        | 키오스크 매장도 선택지에 추가해 다양한 매장 이용하고 싶음    |

> **채택 이유**: 가장 보편적인 고령층 패턴. '배우고 싶은데 못 배우는' 유형이 아니라 '배울 의지 없이 그냥 쓸 수 있길 원하는' 유형 → 솔루션이 교육이 아닌 인터페이스 개선이 되어야 함을 명확히 함.

### Step 7. Pain Point 도출

**핵심 Pain Point**

> "키오스크의 터치 기반 UI/UX가 고령층에게 익숙하지 않아, 주문 절차 자체를 완료하지 못하고 타인에게 의존하거나 매장 이용을 포기하게 된다."

**Pain Point 세분화**

| 유형         | 내용                                                         | 페르소나 근거                                      |
| ------------ | ------------------------------------------------------------ | -------------------------------------------------- |
| **프로세스** | 터치 기반 조작 방식이 익숙하지 않아 전체 절차를 스스로 완료하지 못함 | "말로 하면 다 해결됐는데 키오스크는 너무 불편하다" |
| **지원**     | 막혔을 때 즉각 도움받을 수단 없어 주변 사람에게 의존하거나 이용 포기 | 직원 찾거나 옆 청년에게 부탁하는 행동              |
| **생산성**   | 키오스크 피하다 보니 이용 가능한 매장·서비스 선택지 축소     | 키오스크 없는 매장만 선택                          |

### Step 8. POV (Point of View) 작성

```
먹구름 씨는 키오스크 앞에서 말로 묻고 스스로 원하는 일을 처리할 수 있는 방법이 필요하다.
왜냐하면, 터치 기반 키오스크는 먹구름 씨에게 조작 도구가 아닌 의사소통이 불가능한 벽으로
느껴지며, 매번 타인에게 도움을 요청해야 하는 상황이 일상적인 사회활동에서 스스로 배제되고
있다는 자존감의 상처로 이어지기 때문이다.
```

### PRD 작성

#### ① 배경 (Background)

키오스크 보급이 빠르게 확산되면서 터치 기반 UI/UX에 익숙하지 않은 고령층이 공공장소에서 정보 탐색 및 업무 처리에 어려움을 겪고 있다. 고령 인구 증가와 무인화 트렌드가 맞물리며, 디지털 소외 계층의 일상적 사회활동 참여가 점점 제한되고 있다.

- **핵심 페르소나**: 퇴직 후 혼자 외출이 잦아진 70대 먹구름 씨. 키오스크 매장을 기피하면서 서비스 선택폭이 좁아지고, 매번 타인에게 의존하는 상황에서 자존감 하락을 경험 중.
- **해결 방향**: 키오스크에 자연어 기반 인터페이스 도입 → 고령층이 말로 묻고 답하는 방식으로 스스로 주문 완료

---

#### ② 목표 및 핵심 지표 (Goals & KPI)

**제품 목표**: 고령층이 타인의 도움 없이 말로 키오스크 주문을 스스로 완료할 수 있도록 한다.

| 지표                 | 설명                                       | 목표값   | 설정 근거                                                    |
| -------------------- | ------------------------------------------ | -------- | ------------------------------------------------------------ |
| 키오스크 주문 완료율 | 고령층이 타인 도움 없이 스스로 완료한 비율 | 60% 이상 | 현재 65세 이상 키오스크 활용률 18% → 자연어 도입 시 3배 이상 향상 가능으로 판단 |
| 음성 인식 성공률     | 1회 발화로 의도가 정확히 인식된 비율       | 80% 이상 | 고령층 음성 단어 오류율 15~30%를 감안한 목표                 |
| 평균 주문 소요 시간  | 첫 화면 진입부터 결제 완료까지             | 3분 이내 | 기존 평균 주문 시간과 동일 수준 유지 목표                    |

---

#### ③ 범위 (Scope)

**In-Scope**

- 음성 자연어 입력 기반 메뉴 탐색 및 주문
- 단계별 음성 안내 및 현재 상태 피드백
- 키오스크 터치 조작 실패 시 음성 재시도 유도
- 식당·카페 키오스크 환경

**Out-of-Scope**

- 병원·교통·관공서 등 타 키오스크 환경 (v1.0 이후 확장 예정)
- 스마트폰 앱 또는 웹 기반 서비스
- 한국어 외 다국어 지원
- 키오스크 하드웨어 설계 및 제조
- 결제 시스템 자체 개발 (기존 결제 모듈 연동)

| F-06 | 음성 인식 실패 재시도    | 인식 실패 시 재발화 유도, 2회 연속 실패 시 대안 안내         | UC2-2, UC2-4  |
| F-07 | 직원 호출 연동           | 음성·터치 모두 실패 시 직원 호출 버튼 표시 + 호출 신호 전송  | UC2-4         |
