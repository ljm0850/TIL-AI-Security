## 진행 과정

### Step 1. Streamlit 강의 코드 실습

강의 자료의 `dashboard.py`, `chatbot.py` 코드를 순서대로 따라 작성하며 실행 확인.

- KPI 대시보드(`st.metric`, `st.columns`), Plotly 차트, Matplotlib 히스토그램 직접 실행
- AI 챗봇 UI (`st.chat_input`, `st.chat_message`, `session_state`) 흐름 확인
- 동료들의 Python 문법 이슈 지원 (아래 별도 기록)

**동료 지원 내역**

| 이슈 | 원인 | 해결 |
|---|---|---|
| `IndentationError` | 강의 PDF에서 코드 붙여넣기 시 들여쓰기가 깨져 있었음 | Python은 들여쓰기로 코드 블록을 구분한다고 설명, 스페이스 4칸 기준으로 직접 수정 |
| `SyntaxError` (한글) | 주석 처리 없이 한글 설명을 코드 안에 그대로 작성 | `#` 주석의 역할 설명 — `#` 없는 한글은 Python이 코드로 인식해 오류 발생 |

#### 발주 주제: 스터디 모집 매니저 AI

**발주 배경**

현재 인공지능 사관학교 자율스터디 모집 양식의 문제를 직접 겪으면서 발주.

기존 양식:
```
스터디명 :
스터디 주제 :
모집 인원 : 00명
스터디장 Discord : @아이디
```

이 양식만으로는 스터디가 실제로 어떻게 운영될지 전혀 알 수 없다. 모르는 것을 공부하려고 스터디를 구성하는데, 정작 "무엇을 어떻게 공부할지"가 빠져 있는 구조다.

**원하는 기능**

- 스터디 주제 입력 → 스터디 방식 고도화 제안
- 커리큘럼 자동 초안 작성
- 스터디 기한 및 일정 제시

---

#### 수주 주제: 돈버는 공시 알리미

**주제 파악을 위한 사용자 검증 질문**

1차 질문을 통해 핵심 페인포인트를 파악하고, 2차 질문으로 기능 방향을 구체화했다.

**핵심 Pain Point**: DART·증권플러스 등 기존 앱의 알림은 공시·뉴스·리포트가 뒤섞여 있어 중요한 공시를 구분하기 어렵고, 결국 알림을 무시하게 된다.

**기능 방향 결론**
- 관심 종목 공시만 필터링
- 유상증자·계약체결 등 카테고리를 사전 정의하고 사용자가 원하는 유형을 선택
- 공시 빠른 수신이 AI 요약보다 우선 — 수신 후 빠른 판단을 돕는 구조
- Streamlit 환경 제약 상 즉각적인 실시간 알림 구현은 어려울 수 있어 확인 필요

**페르소나 도출**

| 구분 | 페르소나 1 | 페르소나 2 |
|---|---|---|
| 이름 | 김재현 | 이서연 |
| 특징 | 주식 1년차 개인 투자자 | 주식 6개월차 공시 초보 대학생 |
| 핵심 니즈 | 원하는 공시 유형만 빠르게 필터링 | 어려운 공시 용어를 쉽게 해석 |
| Pain Point | 알림 과다로 중요 공시 놓침 | 공시 용어 이해 어려움, 중요도 판단 불가 |
| POV | 관심 종목의 중요한 공시만 빠르게 보고 싶은 투자자에게 공시 유형 필터링과 중요도·요약 알림을 제공해야 한다 | 공시 용어가 어렵고 알림이 많은 초보 투자자에게 관심 종목 중심으로 공시를 요약·설명하고 중요도를 표시해주는 서비스가 필요하다 |

## 느낀 것 / 배운 것

- 동료들의 Python 이슈를 도우면서, 에러 메시지를 읽는 습관이 얼마나 중요한지 다시 느꼈다.
- 발주/수주 방식으로 프로젝트를 진행하니 "내가 원하는 걸 만드는 것"과 "상대방이 원하는 걸 파악하는 것"이 동시에 훈련된다. 특히 수주 주제에서 사용자 검증 질문을 직접 설계하는 경험이 인상적이었다.
- 공시 알리미 주제에서 "빠른 수신이 AI 요약보다 우선"이라는 사용자의 답변이 인상 깊었다. AI 기능이 항상 핵심이 아닐 수 있다는 걸 다시 확인했다.
