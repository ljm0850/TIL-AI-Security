## 실습 개요
- **목표**: 정답 레이블 없는 환경에서 사용자 행동 로그로 내부자 위협 징후를 탐지하고, Anomaly Score로 위험 사용자를 식별한다.
- **방법**: CERT Insider Threat 데이터셋을 모방한 행동 특징 + `StandardScaler` + `IsolationForest`(비지도).

---

## 진행 과정

```
Step 1. 데이터 생성   # generate_user_behavior() → 정상 400 / 내부자 30
                     # 내부자는 exfiltration / sabotage / espionage 3유형
Step 2. 데이터 분리   # 학습: 정상 데이터만(280) ← 비지도라 정상 패턴만 학습
                     # 테스트: 정상 120 + 내부자 30 = 150 (셔플)
Step 3. 정규화        # StandardScaler (특징 단위가 제각각이라 필수)
                     # 주의: scaler는 학습(정상) 데이터에만 fit
Step 4. 학습          # IsolationForest(n_estimators=100, contamination=0.05)
Step 5. 예측 변환      # -1(이상) → 1, 1(정상) → 0 으로 라벨 정합
Step 6. 평가          # 평가에만 label 사용 (학습에는 미사용)
Step 7. 이상 점수 랭킹  # score_samples 하위 10건
Step 8. 신규 사용자 3명 판정
```

**실제 출력 (np.random.seed(42) 고정)**
```
총 데이터 수: 430개   정상 400 / 이상 30

              precision    recall  f1-score   support
          정상      1.00      0.97      0.99       120
          공격      0.91      1.00      0.95        30
    accuracy                           0.98       150
   → 오탐 3건 (정상을 위협으로), 미탐 0건

이상 점수 상위 10개 (낮을수록 이상)
  UserID    Score   실제레이블   야간로그인  민감파일   업로드KB
  U010     -0.749   [위협]           2       100   4,601,153
  U004     -0.749   [위협]           3       111     623,199
  U046     -0.749   [위협]           3        79   4,188,190
  U041     -0.749   [위협]           3       188   3,577,026
  U018     -0.741   [위협]           2       177     894,798
  ... (상위 10건 전부 실제 위협, 오탐 없음)

신규 사용자 판정
  일반 직원 (정상 패턴)                  → 정상 (점수 -0.391)
  데이터 유출 의심 (야간 대용량 업로드)    → 이상 (점수 -0.735)
  파괴 행위 의심 (새벽 권한 상승 반복)     → 이상 (점수 -0.702)
```
