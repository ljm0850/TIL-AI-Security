## 이번 주 배운 것
> 핵심 테마 3가지로 압축

- **머신러닝 알고리즘 "지형도"가 거의 다 채워졌다.** 지도학습 분류(KNN·SVM·결정트리·앙상블·로지스틱), 지도학습 회귀(선형·다항·규제), 비지도(K-Means·PCA)까지 한 주에 훑었다. 개별 암기보다 "이 문제엔 뭐가 맞나"를 고르는 지도가 생긴 게 핵심 — 예: 해석이 중요하면 선형/트리, 경계가 복잡하면 SVM, 분산 줄이려면 앙상블, 차원 줄이려면 PCA.

- **모델을 "근거 있게" 고르고 검증하는 워크플로를 몸에 익혔다.** EDA → 전처리(결측/이상치/인코딩/스케일) → 여러 모델 교차검증 비교 → 최적 모델 선택 → 평가지표 해석 → feature importance/회귀계수로 설명. 금요일 펭귄 과제에서 이 한 바퀴를 처음부터 끝까지 혼자 돌렸다. "느낌으로 모델 선택"이 아니라 "교차검증 평균±표준편차로 선택"이 된 게 가장 큰 변화.

- **ML과 DL이 한 줄기로 이어졌다.** 금요일에 회귀(특히 로지스틱)를 배운 직후 딥러닝에 들어가니, "뉴런 하나 = 선형회귀 + 활성화 함수"라는 그림이 바로 잡혔다. 퍼셉트론의 XOR 한계 → 다층으로 넘어가는 동기까지, 딥러닝이 완전히 새로운 게 아니라 지금까지 배운 회귀의 확장이라는 감을 얻음.

## 이번 주 만든 것 / 기여한 것
- **분류 실습**: Titanic 생존 예측, KNN 농구선수 포지션 분류, SVM GridSearch, 결정트리/랜덤포레스트/XGBoost(iris·digits), 펭귄 3종 RF 분류 종합 과제(test accuracy 100%, EDA→인코딩→교차검증 모델비교→importance 해석).
- **회귀 실습**: 보스턴 집값 다중 선형회귀(R²·MSE 평가 + 회귀계수 식 복원·해석).
- **비지도 실습**: K-Means 붓꽃 군집(엘보우·실루엣), PCA 손글씨 64→25차원 축소·복원.
- **딥러닝 실습**: 퍼셉트론으로 AND/OR/NAND 게이트 구현(가중치 조정만으로 게이트 전환).
- **바이브코딩**: KNN Pipeline 리팩터링 중 Claude Code가 StandardScaler를 자동 삽입한 걸 발견 → AI가 놓친 도메인 맥락(경기당 수치 정규화)을 따로 기록.

## 나는 지금 어떤 문제를 풀 수 있는가
- **라벨 있는 분류 문제**를 받으면 EDA부터 모델 선택·평가·해석까지 한 파이프라인으로 혼자 처리할 수 있다.
- **회귀 문제**도 같은 워크플로 + 회귀계수로 "어떤 feature가 결과를 어느 방향으로 미는지" 해석할 수 있다.
- **비지도 문제**에서 군집 수를 엘보우/실루엣으로 정하고, PCA로 차원을 줄여 시각화·경량화할 수 있다.
- 모델 선택을 **교차검증 수치(평균±표준편차)** 로 근거 있게 설명할 수 있다.

- 한마디로 **아주 재밌는 한 주**였다. 머신러닝은 나에게 완전히 새로운 분야라, 배우는 것 자체가 재미있었다. 주중에 다쳐서 몸이 좀 아팠는데도 그걸 잊을 만큼 몰입했다. 새 분야에 이렇게 빠져드는 감각이 오랜만이라 좋았다.
