## 이번 주 배운 것

- **Spring Boot MVC 전체 계층을 손으로 쌓아 올렸다.** `Dept.java → XML → Repository → Service → Controller` 순서로 직접 치면서, 각 계층이 왜 그 순서로 만들어지는지 몸으로 이해했다. Django 때는 뭉쳐 있던 게 Spring에서는 명확히 분리되어 있어서 오히려 구조가 더 잘 보였다.
- **바이브 코딩에서 문서가 틀리면 코드도 틀린다.** Oracle 12c+ 기준으로 Skill 문서를 썼는데 실제 환경이 11g였다. AI는 문서에 적힌 대로만 만든다. 환경 정보를 정확히 기입하는 것 자체가 설계의 일부라는 걸 직접 겪었다.
- **Python 데코레이터, NumPy, Pandas의 핵심을 짧게 훑었다.** 데코레이터는 Spring AOP `@Around`와 본질적으로 같다는 게 바로 연결됐다. NumPy는 수치로 실감했다 — for 루프 62ms, NumPy 3.5ms. Pandas는 아직 손에 안 익었지만 `groupby`, `shift`, `rolling`, `melt` 같은 패턴이 어디에 쓰이는지는 감이 왔다.
