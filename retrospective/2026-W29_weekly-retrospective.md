## 이번 주 배운 것
> 강의 및 실습에서 핵심적으로 가져가는 개념 3가지 이내

- **RAG 파이프라인 전체 흐름** — 청킹 → 임베딩 → 벡터DB → 리트리버 → 질의증강. 검색으로 끌어온 외부 문서가 그대로 프롬프트에 들어간다는 점에서, RAG는 성능 구조이자 동시에 외부 입력이 모델에 닿는 경로
- **CI/CD 파이프라인을 처음부터 끝까지** — PR마다 pytest·ruff로 자동 검증(CI) → 멀티스테이지 Docker 이미지화 → ECR 저장 → ECS 실행 → ALB 트래픽(CD). 이번 주를 관통한 감각은 **"돌아가게 만드는 것"과 "팀이 운영 가능하게 만드는 것"은 다른 일**이라는 것. 검증을 사람 손이 아니라 파이프라인에 맡기는 순간부터가 후자
- **배포 자동화의 인증과 격리** — 자동 실행되는 파이프라인은 곧 credential이 주입되는 표면이다. 그래서 장기 Access Key 대신 OIDC로 매번 짧게 사는 임시 자격증명을 받고, Trust Policy로 특정 repo만, PassRole은 `ecs-tasks`로만, SG는 ALB용과 Task용으로 나눈다. 최소권한·격리라는 원리가 OS·컨테이너에 이어 배포 파이프라인에서 또 반복됐다.

## 이번 주 만든 것 / 기여한 것
> 실습 결과물, 팀 활동 기여 등 구체적인 산출물

- **RAG 리트리버 챗봇** — 노트북 프로토타입 → 모듈화 → Streamlit 챗봇으로 이어지는 구조.
- **CI 워크플로우** — PR·push마다 pytest(순수 함수 + FastAPI 엔드포인트) + ruff를 자동 실행. 의도적으로 테스트를 깨뜨려 병합이 실제로 차단되는 것까지 확인.
- **멀티스테이지 Dockerfile** — builder/runtime 분리, `HEALTHCHECK` 포함. + 커밋 해시 태그로 빌드·검증하는 `docker-build` 워크플로우.
- **AWS 배포 파이프라인** — OIDC 배포 역할(Trust Policy `sub` 제한 + PassRole 조건 스코핑), ECR 리포·Push 워크플로우, ECS 클러스터/태스크정의/서비스, ALB·Target Group. push 한 번으로 퍼블릭 엔드포인트 `/health`까지 도달.
- **ECS/ALB 헬스체크 타임아웃 트러블슈팅 문서** — 소거법 11단계 점검 기록과 근본 원인(ALB에 Task용 SG 오연결), 해결 절차 정리.
- Git 브랜치 전략 → feature 브랜치 → PR → 리뷰 코멘트 반영 → merge → 브랜치 정리, 충돌 해결·되돌리기·hotfix 흐름 복습.

## 나는 지금 어떤 문제를 풀 수 있는가
> 이번 주 학습을 통해 새롭게 할 수 있게 된 것

- 빈 저장소에 **PR마다 자동으로 테스트·린트가 도는 CI를 붙일 수 있다.** pyproject.toml로 의존성·도구 설정을 한곳에 모으는 것부터 워크플로우 YAML 작성까지.
- **컨테이너 배포 장애를 계층별로 나눠 진단할 수 있다.** "Request timed out"이면 앱이 아니라 네트워크 경로부터 의심하고, ECS Exec으로 컨테이너 내부에서 직접 응답을 확인해 앱 정상 여부를 먼저 확정한 뒤, SG·라우팅·NACL을 소거법으로 좁혀 나가는 순서.
- 배포가 잘못됐을 때 **이전 태스크 정의 리비전으로 되돌리는 것**과, 그 롤백이 DB 스키마·외부 상태까지는 되돌리지 않는다는 한계를 구분할 수 있다.

## 아직 부족한 것

- **FastAPI는 개념만 훑고 지나갔다.** Depends, response_model, SQLAlchemy 세션 관리 등은 실습으로 만져본 게 없어서 아직 "안다"고 말하기 어렵다.
- **AWS 운영 감각이 얕다.** 비용 구조(ALB·ECR은 desired-count 0으로도 계속 과금), 스케일링, 실패 시나리오를 의도적으로 만들어 검증해본 경험이 없다. 스트레스 테스트도 아직.
- **보안 관점이 아직 "강의에서 짚어준 것"에 머물러 있다.** OIDC·PassRole·SG 분리는 손으로 해봤지만, 내가 스스로 위협 모델을 세워 "여기가 표면이다"를 먼저 찾아낸 건 아니다. 다음 단계는 이걸 뒤집는 것.
